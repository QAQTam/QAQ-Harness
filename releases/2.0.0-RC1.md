## 已知问题

- **包未签名**：macOS 会触发 Gatekeeper、Windows 会触发 SmartScreen 警告。要消除需在 CI
  中配置签名证书（`APPLE_*` / Windows 代码签名 secrets）。
- **CI 首跑曾失败**（run `38550332583`，21 秒五平台全红）：`actions/checkout` 默认浅克隆
  （`depth=1`），契约断言 `git merge-base --is-ancestor` 找不到历史提交。已改为
  `fetch-depth: 0`；修复后首跑为 run `38550470303`。
- macOS 的 Intel 包是**交叉编译**产物（在 arm64 runner 上 `--target x86_64-apple-darwin`）。
